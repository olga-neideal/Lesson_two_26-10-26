# Послание

Небольшой сайт: человек открывает страницу, получает **послание дня** — текст, пожелание и картинку.

Послание дня выбирается по календарной дате. Кнопка «Удиви меня» достаёт случайное письмо из той же коллекции.

## Как запустить

Сайт статический, сервер не обязателен.

1. Открой `index.html` в браузере  
   или подними локальный сервер:

```bash
python -m http.server 8080
```

2. Перейди на [http://localhost:8080](http://localhost:8080)

## Что внутри

| Файл | Зачем |
| --- | --- |
| `index.html` | Лендинг и экран послания |
| `css/styles.css` | Оформление |
| `js/messages.js` | База посланий и картинок |
| `js/app.js` | Выбор послания, копирование, шаринг |
| `Послание.html` | Короткий переход на `index.html` |

## Как добавить своё послание

В `js/messages.js` добавь объект:

```js
{
  type: "Доброе",
  icon: "🌷",
  title: "Заголовок",
  text: "Текст письма.",
  wish: "Пожелание.",
  author: "Подпись",
  image: "assets/flowers.svg",
  imageAlt: "Краткое описание картинки"
}
```

## Публикация

Подойдёт любой хостинг статики: GitHub Pages, Netlify, Cloudflare Pages. Корень сайта — эта папка, стартовая страница — `index.html`.
